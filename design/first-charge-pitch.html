Technical notes — onboarding
  • A plain SwiftUI window shown when ~/.stark/onboarded is absent; menu-bar item gets a "Run setup again" entry.
  • Step 2 polls AXIsProcessTrusted() every second and deep-links to x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility. No restart needed.
  • Step 3 records the combo with a local NSEvent monitor, writes hotkey to config, re-registers live.
  • Step 5 drives the exact production path (selection → model → paste back), so setup ends with proof, not promises.
  • Confetti via CAEmitterLayer — no dependencies, and skipped under Reduce Motion.
About Unsplash backgrounds — the on-device answer
  • Recommended: ship 5 bundled backgrounds (curated Unsplash downloads, baked into the app at build time — ~2 MB, license permits it). Zero network at runtime, works in the Wi-Fi-off demo.
  • Optional sparkle: if online at first launch, fetch one fresh daily photo and cache it forever. One request, ever, clearly labeled in the UI.
  • Alternative: generated aurora gradients (like the mockups above) — zero bytes, animated cheaply with Metal/Core Animation, and they match the bolt identity. My pick if you want purity.

Technical notes — personas 
"personas": {
  "com.tinyspeck.slackmacgap": ["friendly", "concise"],
  "com.apple.mail":            ["formal"],
  "com.apple.Notes":           ["bullets"],
  "com.microsoft.VSCode":      ["typos"]
}
  • PanelController already holds the frontmost NSRunningApplication — its bundleIdentifier keys the map. Zero new permissions.
  • Honest limitation: the model was trained on single style tags. "Friendly + Concise" runs as two sequential passes (~2× time, still ~2 s for a chat message). The proper fix is retraining with combo tags — make_stark_data.py can synthesize those pairs. That's the "Custom personas" card below.
  • Browser tabs (Gmail vs. Twitter in Chrome) are all one bundle ID — app-level only for v1; tab-aware personas would need another permission, not worth it yet.
  • Menu bar shows the active persona for the current app; "Rewrite As" submenu stays as manual escape hatch.

03Auto-organize

The bullets style is already trained and working — this gives it a front door. When the selection looks like a brain-dump, Stark offers to structure it.

You wrote
so for the offsite we need to book the venue before friday and also dana said catering needs a headcount by wednesday and someone has to own the agenda, probably me, and we still havent decided if remote folks join by zoom
→
Stark organizes
  • Book the venue before Friday
  • Send catering headcount to Dana by Wednesday
  • Own the agenda (me)
  • Decide whether remote folks join by Zoom
Technical notes — auto-organize
  • Heuristic, not a model call: selection > 40 words, ≤ 1 line break, ≥ 3 "and/also/then" connectives → the panel shows a one-key suggestion: "Looks like a list — press B to organize."
  • In Notes/Obsidian personas it's simply the default style, no suggestion needed.
  • Long documents already chunk per paragraph, so organizing multi-page notes works today.

04The idea board

Ranked by value against effort. S/M/L = roughly a session, a day, a weekend.

Build now · quick wins

S

Undo rewrite

⌃⌥Z restores what the rewrite replaced, even after pasting. Stark holds the original in memory — one keystroke of insurance makes people fearless.

S

Personal dictionary

Words the model must never "fix" — Hiver, Bayzat, teammate names. A deterministic pass after the model, so it's 100% reliable.

M

Personas v1

Single-style app mapping (everything above except combos). The config plumbing exists; this is mostly the mapping and menu UI.

M

First Charge onboarding

The five screens above. Highest leverage if anyone besides you ever installs Stark.

Next charge · polish

M

Before / after diff

Word-level highlights in the panel showing exactly what changed — builds trust, catches the model's rare bad edit before it ships.

S

Stats & streaks

"3,412 words polished this week. Slack is your busiest room." Counters only, stored locally — the numbers are fun and prove value.

S

Rewrite history

Last five rewrites in the menu bar, click to re-copy. Opt-in, since it stores text.

S

Launch at login

A checkbox on the last onboarding screen. Utilities that require remembering aren't utilities.

Big swings · weekend projects

L

Custom personas (retrain)

Train combo tags (friendly-concise) and user-defined voices ("my standup style") into the model itself. The data pipeline already exists.

L

Voice memo → clean note

Apple's on-device speech-to-text, then auto-organize. Ramble at your Mac, get structured notes. Still zero cloud.

M

Turbo mode

Auto-switch to the 0.5B model for long documents — the chunker makes quality loss small, and multi-page drops toward ~6 s.

Suggested order

  1. Personas v1 + auto-organize — biggest daily-use win, smallest build.
  2. Undo + personal dictionary — the two trust features, both small.
  3. First Charge onboarding — the fun one, best built once personas exist so screen 4 is real.
  4. Then pick from the board.
